# Project Notes

## Simple explanation for viva

**What is customer segmentation?**
It means dividing customers into groups based on similar purchasing behavior.

**Why clustering?**
There is no predefined target label such as Yes/No. The algorithm discovers groups automatically.

**Why K-Means?**
K-Means is simple, fast, and suitable for grouping numeric customer features.

**What does standardization do?**
It puts features on comparable scales so a large-valued feature does not dominate the distance calculation.

**What is silhouette score?**
It measures how well-separated and compact the clusters are. Higher values generally indicate better-defined clusters.

**What are the project inputs?**
Total spending, number of purchases, purchase frequency, average order value, and recency.

**What is the output?**
A customer cluster/segment and a simple business interpretation.
